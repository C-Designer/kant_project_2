# 브랜드 v0.3 앱 검증 — 2026-10-11

사전 범위: 홈·입력·예시 결과·공유·관리 화면의 새 디자인과 기존 흐름을 확인한다. 로컬 가상 예시만 사용하며 실제 사용자 정보나 상용 API는 사용하지 않는다.

기대: 홈 제목/CTA와 네 축이 읽히고 가로 넘침이 없어야 한다. 입력 화면의 생시 모름은 시간 입력을 비활성화한다. 예시 결과에는 fixture 안내와 네 축이 표시된다. 공유 동의 후 링크 생성 및 별도 화면 조회가 가능하고, 관리 화면의 삭제 확인 취소는 정상 복귀한다. 키는 캡처·보고서에 남기지 않는다.

빌드: `npm --prefix frontend run build` 통과(TypeScript 포함).

## 관찰 결과

- Codex IAB에서 실제 앱 `http://127.0.0.1:3100/` 관찰. 홈 CSS1280·390·320px에서 문서 scrollWidth가 viewport와 동일했다. 입력과 예시 결과는 320px에서도 동일했다.
- 홈 큰 제목·굵기 대비·추상 그래픽·주 CTA를 직접 캡처로 검토했다. 결과는 어두운 표지와 밝은 해설 영역, 네 축의 행 구조로 표시된다.
- 입력의 생시 모름 체크 후 해당 시간 입력 비활성 확인.
- 예시 버튼으로 고정 결과, fixture 안내, 네 축 및 공유 동의 UI 확인. 동의 전 공유 버튼 비활성.
- 동의 후 공유 저장 성공, 별도 탭에서 동일한 결과 제목 조회 성공.
- 관리 화면에 이번 확인용 삭제 정보를 입력해 확인창을 열었다. 초기 초점은 돌아가기. Escape로 닫힌 후 공유 결과 삭제 버튼으로 초점 복귀.
- 이번 디자인 검토에서는 최종 삭제를 실행하지 않았다. 생성한 로컬 고정 예시 한 건은 기존 7일 만료 정책을 따른다. 이전 최종 삭제 기능 검증은 docs/VALIDATION.md에 있다.
- 해당 탭에서 수집한 warning/error 0건. 브라우저 네트워크 trace·스크린리더·모든 폭/최대 길이·200% 확대 검증은 이번 범위에 포함하지 않았다.
- 임시 viewport override 복원. 공유 키는 보고서와 캡처에 남기지 않았다.
