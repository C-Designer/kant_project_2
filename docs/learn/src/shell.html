러브코드로 배우는 FastAPI와 LangChain

요청 한 건이 지나는 순서대로 코드를 한 줄씩, 그리고 그 코드가 배포되어 도는 곳까지

      코드 블록의 "다음 줄" 을 누르면 실행 순서대로 한 줄씩 강조되고 설명이 따라옵니다. 점선 밑줄 용어에 마우스를 올리면 뜻이 뜹니다.

      지도

      이 페이지는 러브코드 백엔드의 실제 코드를 교재로 씁니다. 요청 한 건이 서버를 지나는 순서대로 10단계를 따라간 뒤, 그 코드가 배포되어 운영 인스턴스에서 도는 모습까지 2단계 더, 모두 12단계를 따라가며, 각 단계의 관문과 소개를 먼저 보고 필요하면 파일 단위, 원리 단위로 더 깊이 내려갑니다.

        읽는 법

        이 섹션에서 알 것: 각 섹션 머리의 세 줄. 이것만 읽어도 무엇을 배우는지 알 수 있습니다. 끝의 "한 줄 정리"는 면접에서 그대로 말할 수 있는 문장입니다.
        한 줄씩 따라가기: 코드 블록 아래 "다음 줄"을 누르면 실행 순서대로 줄이 강조되고 설명이 바로 아래 붙습니다. 키보드 ←/→ 도 됩니다.
        더 깊이: "한눈에" 섹션이 있는 단계(시작, 해설 체인: 구조, 공유 링크, CI/CD, 배포와 인스턴스)는 "파일 따라가기", "원리 파고들기"가 모두 접혀 있고, 나머지 단계는 가장 얕은 묶음(대개 "파일 따라가기", 테스트 단계는 "원리 파고들기")이 펼쳐진 채 시작합니다. 단계 머리의 관문과 소개만 읽고 다음 단계로 넘어가도 전체 흐름이 이어집니다.
        용어: 점선 밑줄이 있는 용어에 마우스를 올리거나 탭하면 한 문장 정의가 뜹니다.
        개념 체크: 트랙·깊이별 퀴즈 9세트. 단계 끝의 "관련 퀴즈"에서 바로 갈 수 있습니다.

        개념 체크

        트랙과 깊이별로 묶인 퀴즈입니다. 틀린 문항이 하나 이하면 그 세트를 완료로 표시합니다. 진행 상황은 이 브라우저에만 저장됩니다.

        히스토리

        이 코드는 처음부터 지금 모양이 아니었습니다. 첫 MVP 에서 시작해 PR(초기 두 건은 직접 커밋)이 하나씩 무엇을 더하고 바꿨는지 시기별로 보여줍니다. 채워진 점이 찍힌 PR 은 요청 여정의 해당 단계에서 그 결과를 배울 수 있습니다.

        요청 시뮬레이터

        시나리오를 고르면 api.py, service.py, share.py 의 분기를 그대로 따라가며 요청이 어느 관문에서 멈추는지 보여줍니다. "직접 조절" 에서 조건을 하나씩 바꿔 볼 수도 있습니다.

        직접 조절

        점이 찍힌 항목이 기본값과 다른 조건입니다. 지금 요청 경로에 쓰이지 않거나 다른 조건 때문에 결과에 영향이 없는 조건은 숨깁니다.

          보안 헤더 네 개는 response_headers 미들웨어가 boundary 의 조기 거절까지 포함한 응답에 붙입니다(api.py 112~115줄). 처리되지 않은 예외로 생긴 500 에는 붙지 않습니다. 429 중 Retry-After 는 RATE_LIMITED(api.py 104줄)와 ANALYSIS_BUSY(168줄)에만 붙고, DAILY_LIMIT 에는 없습니다.
