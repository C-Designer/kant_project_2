러브코드로 배우는 FastAPI와 LangChain

요청 한 건이 지나는 순서대로, backend/lovecode 코드를 한 줄씩

      코드 블록의 "다음 줄" 을 누르면 실행 순서대로 한 줄씩 강조되고 설명이 따라옵니다. 점선 밑줄 용어에 마우스를 올리면 뜻이 뜹니다.

      지도

      이 페이지는 러브코드 백엔드의 실제 코드를 교재로 씁니다. 요청 한 건이 서버를 지나는 순서대로 9단계를 따라가며, 각 단계에서 먼저 한눈에 보고 필요하면 파일 단위, 원리 단위로 더 깊이 내려갑니다.

        읽는 법

        이 섹션에서 알 것: 각 섹션 머리의 세 줄. 이것만 읽어도 무엇을 배우는지 알 수 있습니다. 끝의 "한 줄 정리"는 면접에서 그대로 말할 수 있는 문장입니다.
        한 줄씩 따라가기: 코드 블록 아래 "다음 줄"을 누르면 실행 순서대로 줄이 강조되고 설명이 옆에 붙습니다. 키보드 ←/→ 도 됩니다.
        더 깊이: 단계마다 "파일 따라가기", "원리 파고들기"가 접혀 있습니다. 한눈에 보기만 읽고 다음 단계로 넘어가도 전체 흐름이 이어집니다.
        용어: 점선 밑줄이 있는 용어에 마우스를 올리거나 탭하면 한 문장 정의가 뜹니다.
        개념 체크: 트랙·깊이별 퀴즈 6세트. 단계 끝의 "관련 퀴즈"에서 바로 갈 수 있습니다.

        개념 체크

        트랙과 깊이별로 묶인 퀴즈입니다. 틀린 문항이 하나 이하면 그 세트를 완료로 표시합니다. 진행 상황은 이 브라우저에만 저장됩니다.

        요청 시뮬레이터

        조건을 바꾸면 api.py 와 service.py 의 분기를 그대로 따라가며 어느 줄에서 멈추는지 보여줍니다. 각 관문의 "이 단계 배우기"를 누르면 여정의 해당 단계로 갑니다.

        응답 헤더 네 개는 response_headers 미들웨어가 모든 응답에 붙입니다(api.py 106~113줄). 429 응답에는 Retry-After 가 추가됩니다.
