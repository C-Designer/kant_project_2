# 브랜드 v0.3 검토 — 2026-10-11

범위: 브랜드 기준 재정의와 독립 HTML 보드. 본앱 기능·UI 적용이나 사용성 테스트가 아니다.

## 근거와 결정

사용자는 기존 화면을 투박하다고 평가하고 `1A / 2A / 3A`로 관계 매거진, 담백하고 영리한 문장, 타이포와 추상 그래픽을 선택했다. 이는 방향 확정의 근거다. 종이/잉크/시트러스, 대표 카피, 굵기 대비, 선의 겹침, 작은 모서리 반경은 해당 방향을 구체화한 디자인 제안이다. 사용자 조사·브랜드 선호도 실험은 하지 않았다.

기준 원본: [디자인 시스템](../DESIGN_SYSTEM.md). 시각 견본: [브랜드 보드](./brand-board.html).

## 관찰한 결과

- surface: 설치된 Python 표준 HTTP 서버로 독립 HTML을 제공하고 host-managed Codex IAB/CUA에서 직접 렌더를 관찰했다. 외부 페이지·계정·API 호출 없음.
- 실행: 프로젝트 루트에서 `python3 -m http.server 8891 --bind 127.0.0.1 --directory docs/design`, 주소 `http://127.0.0.1:8891/brand-board.html`.
- desktop: 요청 viewport1280px, 실제 CSS innerWidth1163px. scrollWidth1163px로 가로 문서 넘침 없음. 한글 제목의 굵기 차이, 추상 선 그래픽, 구분선, palette/type/모티프/결과 견본을 전체 지면에서 관찰했다.
- mobile: 실제 CSS390px에서 scrollWidth390px. 제목→설명→CTA 견본→추상 그래픽 순서가 보이며 첫 화면의 제목·버튼이 잘리지 않는 것을 확인했다. 캡처 직후 배율 적용 지연이 있어 reload 후 다시 관찰했다.
- 콘솔에서 수집된 warning/error0건. 네트워크 trace·보조기술·200%글자 확대·모든 폭의 검증은 하지 않았다.
- [대비 계산](./contrast.json): 본문·보조·버튼·입력 경계·포커스·상태9조합이 각 설계 기준을 만족한다. 전체 접근성 준수 인증은 아니다.

캡처는 직접 작성한 브랜드 견본이며 개인 정보·키가 없다. 로컬 프로젝트의 검토 증거로 보관한다. [데스크톱](../../artifacts/qa/brand-v03-desktop.png), [모바일](../../artifacts/qa/brand-v03-mobile.png). PNG는 Git 제외 상태다. 필요가 끝나면 이 두 캡처 파일만 제거할 수 있다. 임시 viewport override는 복원했다.

## 남은 범위

- 최종 로고 벡터 원본·전용 서체는 미확정. 보드에서는 기기 내 폰트만 사용했다.
- 16개 그래픽을 유형에 일대일 대응시키지 않았다. 결과의 정확한 네 라벨이 의미를 담당한다.
- 보드의 버튼은 동작 없는 스타일 견본이며 이를 실제 분석 버튼으로 검증하지 않았다.
- 현재 앱은 v0.2다. v0.3 적용 후 입력·오류·결과·공유·삭제·포커스·모바일 전체 흐름을 다시 확인해야 한다.
