# 러브코드 16유형 라벨링 판단 기준 (v1.2, 확정)

> 우선순위: **7절(v1.2) > 6절(v1.1) > 2절(v1.0)**. 앞 절과 다르면 뒤 절을 따릅니다. v1.2는 1차 라벨 8개 배치가 서로 다르게 해석한 빈 곳을 하나로 확정한 것입니다.

> v1.1 (10/12): 파일럿 50쌍 교차 라벨링에서 나온 애매한 점을 6절 "보완 규칙"으로 정리했습니다. 6절이 2절과 다르면 6절을 따릅니다.

이 문서는 가상 커플 600쌍에 **16유형 중 1개**를 붙이는 기준입니다. 상용 LLM의 1차 라벨, 팀원 검수, 두 사람 교차 라벨링에 모두 같은 문서를 씁니다.

## 0. 기본 원칙

1. **커플 단위로 판단합니다.** 개인 성향이 아니라 "이 두 사람이 만났을 때 관계가 어떤 모양이 되는가"를 봅니다. 두 사람의 성향이 달라도 커플의 답은 하나입니다.
2. **두 극은 우열이 없습니다.** 닮은꼴과 보완형, 열정형과 안정형은 스타일 차이입니다. "좋은 궁합이니 ○○형" 같은 판단은 하지 않습니다.
3. **개수를 세지 말고 맥락으로 판단합니다.** 같은 충이라도 상대의 기신을 눌러 주면 활력이 되고, 필요한 기운을 막으면 부담이 됩니다. 관계 목록의 [태그]를 반드시 읽습니다.
4. **위치 중요도:** 일간끼리(중요도 4) > 일지끼리·암합(3) > 월지가 낀 관계(2) > 나머지(1). 중요도 1 관계 여러 개보다 중요도 3~4 관계 하나가 더 무겁습니다.
5. **사주가 주, MBTI는 보조입니다.** 사주 근거가 한쪽으로 뚜렷하면 사주를 따르고, 사주 근거가 엇갈리거나 약할 때 MBTI로 결정합니다. 단, 축마다 정한 MBTI 글자가 두 사람 모두 같으면(예: 둘 다 I) 무게를 한 단계 올립니다.
6. **분포를 맞추려고 판단을 바꾸지 않습니다.** 결과가 한 유형에 몰려도 근거대로 붙입니다.
7. **생시 모름(시주 제외)** 은 감점 요소가 아닙니다. 남은 여섯 글자로 판단합니다.

## 2. 축별 판단 기준

### 2-1. 연애 케미: 닮은꼴 / 보완형
**묻는 것:** 비슷해서 편한 커플인가, 달라서 서로 채워 주는 커플인가?

| 닮은꼴 쪽 신호 | 보완형 쪽 신호 |
|---|---|
| 오행 분포 유사도 0.85 이상 | 오행 분포 유사도 0.65 미만 |
| 일간 오행이 같음 (서로 비견·겁재) | 온도 정반대 (차가움 + 뜨거움) |
| 같은 계절생, 같은 기후 | 서로 필요한 기운 공급이 양방향 "많음" |
| 두 사람의 필요한 기운이 같음 (같은 것을 원함) | 한 사람에게 없는 오행을 상대가 가짐 |
| MBTI 같은 글자 3~4개 | MBTI 같은 글자 0~1개 |

**결정 순서**
1. 필요한 기운 공급이 **양방향 모두 "많음"** 이거나 **온도 정반대**면 보완형이 기본입니다. 단, 유사도 0.85 이상이고 일간 오행까지 같으면 닮은꼴을 검토합니다.
2. 1이 아니면 유사도·일간 오행·필요한 기운 일치로 닮음 정도를 봅니다. 닮음 신호 2개 이상이면 닮은꼴입니다.
3. 사주 신호가 비슷하게 갈리면 MBTI 같은 글자 수로 정합니다 (3개 이상 닮은꼴, 1개 이하 보완형, 2개면 유사도 0.75 기준).

**주의:** 한쪽만 일방적으로 채워 주는 경우(한쪽 "많음", 반대쪽 "적음")는 보완 신호가 약합니다.

### 2-2. 연애 온도: 열정형 / 안정형
**묻는 것:** 이 관계는 감정 표현이 강하고 뜨겁게 흐르는가, 잔잔하고 꾸준하게 흐르는가?

| 열정형 쪽 신호 | 안정형 쪽 신호 |
|---|---|
| **일간끼리 천간합** (강한 끌림, 가장 무거움) | 합이 육합·삼합·방합 위주이고 충이 없거나 중요도 1뿐 |
| 서로 배우자성 (상대 일간이 내 배우자를 뜻하는 글자) | 서로 비견·겁재·인성 관계 (친구·가족 같은 편안함) |
| 중요도 2 이상의 충·천간충 (자극). 특히 상대 기신을 눌러 주는 충은 "활력" | 합친 온도 차가움 |
| 합친 온도 뜨거움, 또는 둘 중 한 명이 뜨거움 | 두 사람 모두 온화 |
| MBTI: 둘 다 F, 또는 E가 2명 | MBTI: 둘 다 T, 또는 I가 2명 |

**결정 순서**
1. 일간끼리 천간합이 있으면 열정형이 기본입니다. 합의 기운이 두 사람 모두에게 부담이면 끌림은 있어도 소모가 크므로 다른 신호를 함께 봅니다.
2. 일간합이 없으면 "자극 신호(충·배우자성·뜨거운 온도)"와 "편안함 신호(합 위주·비견/인성·차가운 온도)" 중 무거운 쪽을 고릅니다.
3. 엇갈리면 MBTI F/T와 E/I로 정합니다.

**주의:** 충이 많다고 무조건 열정형이 아닙니다. 충이 두 사람 모두에게 필요한 기운을 막는다면 자극보다 피로에 가깝고, 그때는 다른 신호로 판단합니다.

### 2-3. 관계 거리: 밀착형 / 독립형
**묻는 것:** 함께하는 시간이 중심인가, 각자의 영역을 존중하는가?

| 밀착형 쪽 신호 | 독립형 쪽 신호 |
|---|---|
| **일지끼리 육합·반합·암합** (배우자 자리 결속, 가장 무거움) | **일지끼리 충·원진·해·형** |
| 월지끼리 합 (생활환경 공유) | 월지끼리 충 (생활환경이 다름) |
| 서로 배우자성, 일간합 | 일지끼리 관계가 아예 없음 |
| 한쪽이 신약이고 상대가 필요한 기운을 많이 줌 (기대는 구조) | 두 사람 모두 신강 (각자 주관이 뚜렷) |
| MBTI: E 2명, J 2명 | MBTI: I 2명, P 2명 |

**결정 순서**
1. 일지끼리 관계를 먼저 봅니다. 합 계열이면 밀착형, 충·원진·해·형이면 독립형이 기본입니다. 둘 다 있으면(예: 반합이면서 원진) 태그를 보고 누구에게 도움/부담인지로 판단합니다.
2. 일지끼리 관계가 없으면 월지 관계, 배우자성, 강약 조합을 봅니다.
3. 그래도 엇갈리면 MBTI E/I(우선), J/P(보조)로 정합니다.

### 2-4. 갈등 해결: 바로 풀기 / 시간 두기
**묻는 것:** 부딪쳤을 때 그 자리에서 바로 푸는 커플인가, 각자 정리할 시간을 두고 푸는 커플인가?

| 바로 풀기 쪽 신호 | 시간 두기 쪽 신호 |
|---|---|
| 드러나는 갈등(충·천간충)이 숨은 갈등(원진·해·형)보다 무겁다 | 숨은 갈등(원진·해·형)이 충보다 무겁다, 또는 충이 없다 |
| 충이 상대 기신을 눌러 줌 (부딪쳐도 결과가 개운함) | 원진·해가 필요한 기운을 막음 (서운함이 쌓이는 구조) |
| 둘 중 신강이 있음 (주장을 바로 꺼냄) | 두 사람 모두 신약 (회복할 시간이 필요) |
| MBTI: T 2명, 또는 E 2명 | MBTI: F 2명, 또는 I 2명 |

**결정 순서**
1. 관계 목록에서 충 계열과 원진·해·형 계열 중 중요도가 높은 쪽을 고릅니다. 같으면 개수와 태그로 비교합니다.
2. 갈등 관계가 거의 없으면(중요도 1 하나 이하) 강약 조합과 MBTI로 정합니다.
3. 두 사람 성향이 다르면(E와 I 등) "관계에서 실제로 나타날 패턴"을 고릅니다. 사주 갈등 구조가 결정하고, MBTI는 동률일 때만 씁니다.

## 3. 확신도와 메모

- `high`: 네 축 모두 근거가 한쪽으로 뚜렷함
- `mid`: 한두 축이 엇갈려 MBTI나 보조 신호로 정함
- `low`: 두 축 이상이 거의 반반이라 검수자가 꼭 봐야 함

`근거`에는 축마다 결정적인 신호를 짧게 적습니다. 예: `케미: 공급 양방향 많음+온도 정반대 / 온도: 일간 丙辛합 / 거리: 일지 관계 없음, I·P 2명 / 갈등: 원진·해 중요도2 > 충 중요도1`

## 4. 출력 형식 (JSONL, 한 줄에 한 쌍)

```json
{"pair_id": "LC0009", "케미": "닮은꼴", "온도": "안정형", "거리": "독립형", "갈등": "시간 두기", "type_id": "T08", "confidence": "mid", "근거": "..."}
```

값은 반드시 표의 한글 표기 그대로 씁니다 (`바로 풀기`, `시간 두기`는 띄어쓰기 포함).

## 5. 검수 규칙 (팀원)

1. `low` → `mid` → `high` 순서로 봅니다.
2. 고칠 때는 축 단위로 고치고, 바뀐 축과 이유를 검수 시트에 적습니다.
3. 판단 기준 자체가 애매해서 고친 경우 "기준 이슈" 열에 표시합니다. 이 표시가 5건 이상 모이면 기준 문서를 v1.1로 고치고 해당 축을 다시 봅니다.
4. 교차 라벨링: 파일럿 50쌍은 두 명이 서로 보지 않고 따로 붙인 뒤 Cohen's kappa(축별·16유형)를 기록합니다.

## 6. 보완 규칙 (v1.1, 파일럿 결과 반영)

### 공통
- **사주가 MBTI를 이기는 조건:** 한 축에서 사주 신호 차이가 2개 이상이면 사주를 따릅니다. 차이가 0~1개면 MBTI로 정합니다.
- **같은 글자 쌍에 충과 형이 함께 나오면**(예: 寅申, 丑未) 한 건으로 세고 **충**으로 봅니다. 원진·해·형이 같은 쌍에 겹쳐도 한 건입니다.
- **일지 × 월지 교차 관계(중요도 2)** 는 "일지끼리 관계"보다 약하고 "월지끼리 관계"와 같은 무게로 봅니다.
- **두 사람의 일지가 모두 들어간 삼합·방합**은 일지끼리 합 계열로 봅니다.

### 연애 케미
- 닮음 신호: 유사도 0.85 이상, 일간 오행 같음, **같은 계절생**, 필요한 기운 일치. 필요한 기운은 하나라도 겹치면 0.5개, 모두 같으면 1개로 셉니다.
- 보완 신호: 유사도 0.65 미만, 온도 정반대, 공급 양방향 "많음", 없는 오행 채움. **없는 오행 채움은 방향과 관계없이 최대 1개**로 셉니다. 한쪽만 "많음"이면 0.5개입니다.
- 1번 예외(유사도 0.85 이상 + 일간 오행 같음)라도 두 사람의 필요한 기운이 전혀 겹치지 않으면 보완형입니다.

### 연애 온도
- 상대 기신을 눌러 주는 충(중요도 2 이상)은 열정 신호 1개, 필요한 기운을 막는 충은 0.5개로 셉니다.
- 사주와 MBTI가 모두 동률이면 **일간 관계**로 정합니다: 일간이 천간합·배우자성·천간충 중 하나면 열정형, 비견·겁재·인성·식상이면 안정형.

### 관계 거리
- 일지끼리 관계가 없을 때 순서: 일지×월지 교차 관계 → 월지끼리 → 배우자성 → 강약 조합 → MBTI.
- 모두 동률이면 E/I, 그래도 같으면 **독립형**(일지 결속 근거가 없으므로).

### 갈등 해결
- 중요도가 같으면 **개수보다 태그를 먼저** 봅니다. 충이 "기신을 눌러 줌"이고 원진·해·형이 "필요한 기운을 막음"이면 바로 풀기, 그 반대면 시간 두기입니다.
- 원진·해·형이 모두 "기신을 눌러 줌"뿐이면 숨은 갈등으로 세지 않습니다(서운함이 쌓이는 구조가 아님).
- 모두 동률이면 MBTI T/F, 그래도 같으면 충이 하나라도 있으면 바로 풀기, 없으면 시간 두기.

## 7. v1.2 확정 규칙 (가장 우선)

### 7-1. 모든 축에 같은 절차를 씁니다
1. 축의 두 극마다 **사주 신호 점수**를 더합니다 (2절 표 + 6절 + 7-2 가중치).
2. 두 극의 점수 차이가 **1.5 이상이면 사주**를 따르고 끝냅니다.
3. 차이가 1.5 미만이면 2절 표의 **MBTI 칸**으로 정합니다.
4. MBTI도 동률이면 사주 점수가 조금이라도 높은 쪽을 고릅니다. 사주 점수까지 완전히 같으면 6절의 축별 최종 규칙을 씁니다.

2절의 "기본값" 문장(예: 일간합이면 열정형이 기본)은 이제 **강한 신호 2점**이라는 뜻입니다. 반대쪽 사주 신호가 충분해서 차이가 1.5 미만이 되면 MBTI로 넘어갑니다.

### 7-2. 가중치와 빈 곳 처리

| 항목 | 확정 |
|---|---|
| 강한 신호: 공급 양방향 "많음", 온도 정반대, 일간끼리 천간합·천간충, 일지끼리 합 계열 또는 충·원진·해·형 | 2점 |
| 그 밖의 2절 표 신호 | 1점 (6절에서 0.5점으로 정한 것은 0.5점) |
| 같은 신호의 중복 | 같은 글자 쌍은 한 번만 셉니다. "없는 오행 채움"은 축당 최대 1점 |
| 태그가 없는 충·원진·해·형 | 온도·갈등 축 모두 0.5점 |
| 한 관계에 "기신 눌러 줌"과 "필요한 기운 막음"이 함께 붙음 | 온도 0.75점. 갈등 축에서는 "막음"이 있으면 숨은 갈등으로 셈 |
| 월지끼리 원진·해·형 (거리 축) | 독립 0.5점 |
| 일지끼리 합 계열과 해·형이 함께 있음 (거리 축) | 태그로 비교하고, 그래도 같으면 합 계열(밀착)에 0.5점 추가 |
| 거리 축에서 일지끼리 관계가 없음 | 교차 → 월지 → 배우자성 → 강약 순서의 신호를 **모두 더해** 점수로 비교 (순서는 동점일 때만 씀) |
| 온도 최종 규칙의 일간 관계가 재성·관성인데 배우자성 표시가 없음 | 열정형 (극 관계 = 긴장과 끌림) |
| 케미 축: 닮음 신호가 많아도 보완 신호와 차이가 1.5 미만 | 7-1 절차대로 MBTI로 정합니다 (닮음 2개 이상 규칙보다 7-1이 우선) |

### 7-3. 검수 기록
- 검수자는 기존 라벨이 7절과 다르면 고치고, 바뀐 축과 7절의 어느 항목 때문인지 적습니다.
- 확신도는 7-1의 점수 차이로 다시 매깁니다: 네 축 모두 차이 1.5 이상 `high`, 한두 축이 MBTI나 동점 규칙으로 결정 `mid`, 세 축 이상이거나 사주·MBTI 모두 동률인 축이 있으면 `low`.
