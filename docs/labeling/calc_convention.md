# 만세력 계산 규약 (v1.0)

같은 규약이면 누가 계산해도 같은 팔자가 나옵니다. 아래는 팀이 고정한 선택입니다. 바꾸면 검증(`scripts/verify_manse.py`)을 다시 돌립니다.

## 입력

| 항목 | 규약 |
|---|---|
| 날짜 | 양력만 받습니다. 음력 입력은 나중 고도화입니다. |
| 생시 | 선택 입력입니다. 모르면 시주를 제외합니다(오류 아님). |
| 출생지 | 받지 않습니다. 진태양시(경도) 보정을 하지 않습니다. |
| 지원 범위 | 1940~2030년. 범위 밖은 오류로 응답합니다. |
| 오류 | 존재하지 않는 날짜, 범위 밖 연도, 잘못된 MBTI 형식, 분만 입력 → `ManseInputError` |

## 시각 처리

1. 입력 시각은 **그 당시 한국의 시계 시각**으로 봅니다.
2. tz 데이터베이스(`Asia/Seoul`)로 UTC로 바꾼 뒤 **현재 한국 표준시(UTC+9)** 로 환산합니다. 그래서 아래 시기는 자동 보정됩니다.
   - 서머타임: 1948~1951, 1955~1960, 1987~1988년 (시계가 1시간 빨랐음)
   - 과거 표준시 UTC+8:30: 1954-03-21 ~ 1961-08-09
3. 보정이 들어가면 결과의 `notes`에 "당시 시계 13:20(UTC+10) → 표준시 12:20"처럼 남깁니다.

## 기둥 계산

| 기둥 | 기준 |
|---|---|
| 년주 | 입춘 절입 시각부터 새해 |
| 월주 | 12절(입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한) 절입 시각 |
| 일주 | KST 자정 기준. **23시대 출생은 다음 날 일주** (`sect=1`, 설정으로 바꿀 수 있음) |
| 시주 | 2시간 단위 12지시 (23:00~00:59 子시), 시간은 일간 기준 五鼠遁 |

- lunar-python의 절기표는 **중국 표준시(UTC+8)** 입니다. 그래서 년주·월주는 KST를 UTC+8로 바꿔 절입 시각과 비교하고, 일주·시주는 KST 시계로 계산합니다. (예: 2024 입춘은 lunar-python에서 16:27, KST 17:27)
- 생시 모름이면 그날 12:00 기준으로 년주·월주를 정합니다. 그날이 절입일이라 생시에 따라 월주(입춘이면 년주)가 바뀔 수 있으면 경고를 남깁니다.

## 해석 규칙 (반정량, 팀 규약)

| 항목 | 규약 |
|---|---|
| 지장간 | 한국 통용 표 (여기·중기·정기 일수) |
| 강약 | 비겁+인성 비율. 가중치: 월지 3(득령), 일지 2(득지), 나머지 글자 1. 지지는 지장간 일수 비율로 계산. 0.47 이상 신강, 0.32 이하 신약, 사이는 중화 (1970~2005년생 3,000명 분포로 대략 3등분) |
| 억부 용신 | 신약: 가장 무거운 설기 요소가 재성이면 비겁, 아니면 인성. 신강: 인성이 무거우면 재성, 비겁이 무거우면 관성(관성이 거의 없으면 식상). 중화: 가장 적은 오행 |
| 조후 | 계절(여름 +2, 겨울 −2) + 丙丁巳午 +1, 壬癸亥子 −1, 未戌 +0.5, 丑辰 −0.5. −2.5 이하 차가움(조후 火), +2.5 이상 뜨거움(조후 水) |
| 관계 | 천간합·천간충, 육합·반합(왕지 포함)·충·원진·해·형(자형 제외), 일지 암합(정기끼리 천간합), 두 사람이 함께 만드는 삼합·방합 |
| 맥락 태그 | 충·원진·해·형이 치는 글자가 그 사람의 기신이면 "기신을 눌러 줌", 용신·희신·조후면 "필요한 기운을 막음". 합의 기운이 용신이면 "도움", 기신이면 "부담" |

용신을 정하는 방법은 유파마다 다릅니다(억부·조후·통관·병약). 6일 일정이라 억부 + 조후로 범위를 좁혔고, 이것은 한계로 README에 적습니다.
